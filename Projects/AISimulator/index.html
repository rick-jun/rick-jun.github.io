AISimulator

AI 기반 공정 상태 시각화 및 제어 파라미터 설정을 위한 Windows 데스크톱 시뮬레이션 애플리케이션입니다. 실시간 차트, 웹 대시보드 연동, 동적 테마 엔진을 적용하여 엔지니어링 환경에 최적화된 모니터링 UI를 제공합니다.

WPFC#MVVMCommunityToolkit.MvvmLiveChartsWebView2Dependency InjectionMahApps.Metro

프로젝트 개요

AISimulator는 AI 기반 공정의 운영 상태를 모니터링하고 시뮬레이션 데이터를 시각적으로 분석하는 Windows 데스크톱 애플리케이션이다. 무거운 추론 연산 대신 시뮬레이션 구동, 상태 모니터링, 파라미터 튜닝 인터페이스에 집중하여 산업 자동화 및 데이터 중심 운영 환경에 최적화했다. 실시간 데이터 시각화와 직관적인 제어 요소를 배치해 운영자의 신속한 현장 대응을 지원한다.

주요 설계 목표

실시간 상태 모니터링, 시뮬레이션 데이터 시각화, 제어 파라미터 설정, 외부 웹 대시보드 연동

MVVM 기반 애플리케이션 아키텍처

WPF 및 MVVM 패턴을 적용해 View와 비즈니스 로직을 엄격히 분리했다. CommunityToolkit.Mvvm의 소스 생성기 기반 ObservableObject 및 RelayCommand를 활용해 상형문자식 보일러플레이트 코드를 최소화하고 데이터 바인딩 효율을 높였다. 또한 Microsoft.Extensions.DependencyInjection 기반 DI 컨테이너를 구축해 ViewModel과 서비스 계층 간 결합도를 낮추고 단위 테스트가 가능한 구조를 확보했다.

실시간 데이터 시각화

LiveCharts를 도입하여 시계열 데이터와 주요 공정 지표를 실시간 차트로 구현했다. ViewModel에서 데이터 컬렉션(SeriesCollection)을 갱신하면 UI 바인딩 메커니즘을 통해 실시간으로 플로팅된다. 이를 통해 지연 없는 데이터 동기화를 유지하며 시뮬레이션 상태 변화 추이를 제공한다.

구현 핵심 요소

MVVM 바인딩 패턴 기반 차트 제어, 데이터 로직과 시각화 계층 분리, 실시간 데이터 스트리밍 대응 차트 최적화

WebView2 통합 및 UI 현대화

WebView2를 임베딩하여 기존 HTML5 기반 웹 대시보드 및 원격 모니터링 페이지를 데스크톱 클라이언트 내에 통합했다. 별도의 웹 브라우저 전환 없이 단일 인터페이스에서 웹 데이터와 native 기능을 동시 제어할 수 있어 운영 효율을 높였다. UI 프레임워크로는 MahApps.Metro와 ControlzEx를 적용해 산업용 솔루션에 걸맞은 현대적인 UI 스타일을 유지했다.

동적 테마 시스템 및 유지보수 구조

ControlzEx 기반의 테마 엔진을 연동해 앱 재시작 없이 런타임에 다크/라이트 모드 및 악센트 컬러를 즉시 전환할 수 있도록 구현했다. 변경된 테마 요소는 애플리케이션 전역에 실시간 반영되며, 테마 변경 취소 시 직전 상태로 복구되는 롤백 로직을 갖춰 UI 안정성을 높였다. 장시간 운영되는 중앙 관제 환경의 가독성을 고려한 설계로, 결정적 빌드 구성을 적용해 빌드 재현성과 장기 유지보수성도 강화했다.

런타임 테마 전환 및 롤백, 의존성 주입(DI) 아키텍처, 결정적 빌드(Deterministic Builds) 적용, 데이터 바인딩 중심 UI 구현
