AICraft – Multi-Database Infrastructure Library

MS SQL Server, PostgreSQL, Access 등 다중 데이터베이스 연결과 로그 관리, UI 유틸리티를 제공하는 .NET Framework 기반 클래스 라이브러리.

C#.NET Framework 4.8MS SQL ServerPostgreSQLMicrosoft AccessWPFWinFormsADO.NET

프로젝트 개요

AICraft는 산업 자동화 및 비전 검사 시스템의 기반이 되는 재사용 가능한 인프라 컴포넌트를 제공하는 DLL 라이브러리입니다. 다중 데이터베이스 핸들러, 로그 관리, UI 유틸리티, XML 설정 처리를 포함하며, WinForms 및 WPF 애플리케이션에서 참조하여 사용할 수 있습니다.

아키텍처 개요

라이브러리는 DB 레이어, Common 레이어, UI 레이어의 세 가지 계층으로 구성됩니다. DB 레이어는 MS SQL Server, PostgreSQL, Access 각각에 대한 전용 ADO.NET 핸들러를 제공합니다. Common 레이어는 로그 기록, 파일 로테이션, XML 직렬화/역직렬화를 담당하며, UI 레이어는 자동 종료 메시지 박스(WinForms)와 자동 스크롤 텍스트 박스(WPF)를 포함합니다.

핵심 성과

MS SQL Server, PostgreSQL, Access를 위한 별도 ADO.NET 핸들러 구현 / 24/7 산업 환경을 위한 파일 로테이션 기반 로그 관리 시스템 구축 / WinForms 및 WPF 모두에서 사용 가능한 비차단 UI 컴포넌트 개발 / 운영자 편의를 위한 XML 기반 설정 파일 처리 / 논리적 계층 구조(DB, Common, UI)를 갖춘 클린 아키텍처

주요 엔지니어링 결정

다중 데이터베이스 지원을 위해 별도의 핸들러를 구현하여 ORM 없이도 다양한 환경에 대응할 수 있도록 했습니다. .NET Framework 4.8을 타겟으로 한 것은 기존 산업용 SCADA 시스템 및 레거시 WinForms 애플리케이션과의 호환성을 고려한 결정입니다. WPF와 WinForms를 동시에 지원하는 UI 컴포넌트는 점진적인 UI 마이그레이션 시나리오를 염두에 두고 설계되었습니다.

복잡도 평가

프로젝트 규모는 약 10개의 소스 파일로 구성된 소규모 클래스 라이브러리입니다. 동기식 ADO.NET 호출을 사용하며, 비동기 패턴은 적용되지 않았습니다. FileRotator를 통한 로그 로테이션은 기본적인 신뢰성 메커니즘을 제공하지만, 재시도 로직이나 서킷 브레이커는 구현되지 않았습니다. 매개변수화된 쿼리는 각 핸들러에서 사용될 것으로 예상되나, 소스 코드에서 명시적으로 확인되지는 않았습니다.
